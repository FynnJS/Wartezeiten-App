# Wartezeiten App v1.2.0

Version 1.2.0 brings live wait times directly in the browser, fixes missing statistics measurement points, and makes loading and query times noticeably faster.

## New features

- Live wait times, opening hours, crowd levels, and park statistics are now available directly in the browser — no app installation required.
- The website now supports dark mode, matching the app's visual design.

## Fixes

- Central wait-time measurement points for parks and attractions were not being recorded after the cron migration in v1.1.8. A bug in the scheduled handler prevented statistics from running on the shared `* * * * *` trigger. Statistics now run every minute with rotating four-shard coverage.
- The park list no longer triggers a slow per-park API scan at startup when the "open only" filter is active.
- Switching the UI language no longer triggers a redundant park recommendation scan.
- A failing pre-run D1 snapshot prune no longer aborts the entire shard's statistics run.

## Improvements

- The statistics detail page loads historical day data for up to 8 comparison days in parallel instead of sequentially.
- The statistics index endpoint (`statistics/index.json`) now uses two parallel D1 queries instead of N sequential per-park queries, making attraction search noticeably faster.
- The CI release pipeline validates the APK certificate fingerprint before uploading to prevent update-incompatible APKs.

## Technical

- Android metadata bumped to `versionCode 10200` / `versionName 1.2.0`.
- Worker tests and unit tests cover the changes.
