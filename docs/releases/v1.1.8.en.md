# Wartezeiten App v1.1.8

## User-facing changes

- Mandatory updates now show the changelog fully scrollable and in the selected app language.
- Release builds without the stable release keystore now fail, preventing APKs with incompatible signing from being published.
- Attraction-specific wait-time alerts now only use the selected target attraction and no longer show values from another attraction when the target is closed.
- The language selector in settings now shows flags and native language names, for example "Deutsch", "English", "Français", and "Nederlands".
- Park details now show a warning when opening times say a park has been open for at least 15 minutes but no attraction reports live wait-time data.
- Attribution footers remain fully visible on devices with Android system navigation bars.

## Fixes

- Local push texts now round crowd-level percentages to whole numbers, matching the app and Cloudflare Worker.
- The local WorkManager fallback for wait-time alerts now matches the server-side Worker behavior for attraction-specific alerts.
- D1 statistics snapshots again use the actual Worker collection time as the measurement timestamp, so repeated cron runs with unchanged upstream timestamps no longer overwrite the same point.

## Technical

- Android metadata bumped to `versionCode 10108` / `versionName 1.1.8`.
- `release.json` now supports localized release notes through `releaseNotesLocalized` for German, English, French, and Dutch.
- `isParkOpenWithoutWaitingTimeData` detects likely wait-time source outages using opening times, a grace period, and attraction status.
- Regression tests cover the new data-gap detection and Worker timestamp fix.
