# Wartezeiten App v1.2.0

La version 1.2.0 apporte les temps d'attente en direct directement dans le navigateur, corrige les points de mesure des statistiques manquants et accélère nettement les temps de chargement et de requête.

## Nouvelles fonctionnalités

- Les temps d'attente en direct, les horaires d'ouverture, les niveaux d'affluence et les statistiques des parcs sont désormais accessibles directement dans le navigateur — sans installation d'application.
- Le site web prend désormais en charge le mode sombre, en accord avec le design visuel de l'application.

## Corrections

- Les points de mesure centraux des temps d'attente pour les parcs et les attractions n'étaient plus enregistrés depuis la migration cron en v1.1.8. Un bug dans le gestionnaire de tâches planifiées empêchait les statistiques de s'exécuter sur le déclencheur `* * * * *` partagé. Les statistiques sont à nouveau collectées chaque minute avec une couverture en rotation sur quatre shards.
- La liste des parcs ne déclenche plus un scan API lent parc par parc au démarrage lorsque le filtre "parcs ouverts uniquement" est actif.
- Le changement de langue de l'interface ne déclenche plus de scan de recommandations superflu.
- Un échec du nettoyage préalable des snapshots D1 n'interrompt plus l'ensemble du shard de statistiques.

## Améliorations

- La page de détail des statistiques charge les données journalières historiques pour jusqu'à 8 jours de comparaison en parallèle plutôt que séquentiellement.
- L'endpoint d'index des statistiques (`statistics/index.json`) utilise désormais deux requêtes D1 parallèles au lieu de N requêtes séquentielles par parc, rendant la recherche d'attractions nettement plus rapide.
- La pipeline CI de release valide l'empreinte du certificat APK avant l'envoi pour éviter les APKs incompatibles avec les mises à jour.

## Technique

- Métadonnées Android mises à jour vers `versionCode 10200` / `versionName 1.2.0`.
- Les tests Worker et les tests unitaires couvrent les modifications.
