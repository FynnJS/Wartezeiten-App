# Wartezeiten App v1.1.9

Version 1.1.9 makes loading phases and empty states much easier to understand and hardens central statistics collection after Worker updates.

## User-facing changes

- The park list now clearly explains when the "open only" filter is still checking current opening and wait-time data.
- Park details now show helpful messages during initial loading and when attraction lists are still empty during refresh.
- Park comparison now has its own startup loading state and refreshes selected parks in parallel.
- Statistics, Watchlist, and weather screens now have friendlier loading or empty states and more localized controls.

## Fixes

- Empty lists no longer look like final "no data" results while background loading is still running.
- Central statistic measurement points are more robust after Worker updates because the required D1 statistic tables are ensured before reads and writes.

## Technical

- Android metadata bumped to `versionCode 10109` / `versionName 1.1.9`.
- Worker statistic paths ensure `attraction_history_days`, `attraction_history_snapshots`, and their indexes through `ensureAttractionHistoryD1`.
- `testDebugUnitTest` and Worker tests cover the changes.
