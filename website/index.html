Wie funktioniert das Update?

  1. Die App fragt release.json ab.
  2. Sie vergleicht den remote versionCode mit der aktuellen installierten Version.
  3. Bei neuem Release wird ein In-App-Banner angezeigt.

So kannst du ein neues Update bereitstellen:

  1. Build & signiere die Release-APK in Android Studio oder per Gradle.
  2. Lege die APK in website/releases/ ab.
  3. Berechne den SHA-256 Hash und aktualisiere website/release.json.
  4. Push die Änderungen in dein Cloudflare Pages Repository.

Cloudflare Pages eignet sich ideal für diese statische Präsentation. Du kannst die Website aus dem Ordner website/ deployen.
